# 设计规范（ITER-U04 统一设计系统）

> 版本：**v1.0.0** ｜ 生效日期：2026-10-31 ｜ 适用端：pc-admin（Vue3 + Element Plus）、miniprogram（微信原生 + WXSS）
> 令牌单一来源：`pc-admin/src/styles/tokens.css`（PC） / `miniprogram/app.wxss`（小程序，同名同值）
> 校验脚本：`node scripts/check-design-tokens.js`（`npm run design:check`）

---

## 一、设计原则

1. **令牌优先**：颜色、字号、间距、圆角、阴影一律引用令牌，视图与组件内禁止硬编码色值。
2. **语义分层**：基础色 → 语义令牌 → 组件令牌，三层单向依赖；暗色主题只覆盖语义层，不改基础色。
3. **两端一致**：PC 与小程序使用同名令牌，色值 100% 对齐，仅单位不同（PC `px` / 小程序 `rpx`，1px = 2rpx）。
4. **渐进替换**：不追求一次性重写页面，先令牌化、再组件化、最后按高频页分批迁移，每批可独立验收。
5. **可访问性**：键盘焦点可见（`:focus-visible` 焦点环），状态不只靠颜色表达（标签同时给出文案）。

## 二、令牌分层

| 层级 | 命名前缀 | 用途 | 是否允许原始色值 |
|---|---|---|---|
| 基础色 | `--color-*` | 品牌、中性、状态、成色原始色值 | ✅ 仅 `tokens.css` |
| 语义令牌 | `--bg` `--text-*` `--primary` `--success` … | 表达用途，暗色主题覆盖点 | ❌ 由基础色派生 |
| 组件令牌 | `--sidebar-*` `--chart-*` `--radius-*` `--sp-*` `--shadow-*` | 布局、侧栏、图表、圆角间距 | ❌ 由语义层派生 |

> 旧令牌 `--brand-1` / `--brand-2` / `--brand-ink`（PC）与 `--xy` / `--xy-deep` / `--xy-light` / `--t1~t3` / `--red` / `--green` / `--blue`（小程序）保留为别名，仅作兼容，新代码不得使用。

## 六、暗色主题

- 启用方式：`document.documentElement.classList.add('dark')`，同时写入 `data-theme="dark"`。
- 切换入口：pc-admin 顶栏「月亮 / 太阳」按钮，偏好写入 `localStorage['idlefish.admin.theme']`。
- 首帧无闪烁：`main.js` 在 `createApp` 前调用 `applyTheme(resolveInitialTheme(), false)`。
- 覆盖范围：仅语义层 + 组件层；Element Plus 组件级变量由 `element-plus/theme-chalk/dark/css-vars.css` 提供，品牌主色在 `html.dark` 中重新声明以免被默认蓝覆盖。
- 图表：ECharts 不自动跟随 CSS 变量，`utils/theme.js#chartPalette()` 运行时读取令牌，并监听 `theme-change` 事件重绘。

| 语义令牌 | 亮色 | 暗色 |
|---|---|---|
| `--bg` | `#F4F5F7` | `#141619` |
| `--surface` | `#FFFFFF` | `#1D2025` |
| `--border` | `#ECEDEF` | `#2C3038` |

## 七、组件清单与用法

全局注册于 `pc-admin/src/main.js`，无需逐页 import。

### 7.1 PageHeader（已有）

```vue
<PageHeader title="订单管理" desc="按订单号/状态筛选" :crumbs="['运营后台', '订单管理']">
  <template #extra><el-button type="primary">导出</el-button></template>
</PageHeader>
```

### 7.2 TreeFlatTable（已有）

树形数据扁平化表格，自动缩进与层级标记，用于类目 / 机构 / 菜单。

### 7.3 FilterBar（新增）

```vue
<FilterBar :loading="loading" @search="load" @reset="reset">
  <el-form-item label="关键词"><el-input v-model="keyword" clearable /></el-form-item>
</FilterBar>
```

- 默认渲染「查询 / 重置」；自定义按钮用 `#actions` 插槽。
- 属性：`loading` `showActions` `searchText` `resetText`；事件：`search` `reset`。

### 7.4 PageBar（新增）

```vue
<PageBar :total="total" :page="page" :size="size" @change="onPageChange" />
```

```js
onPageChange({ page, size }) { this.page = page; this.size = size; this.load(); }
```

- 兼容旧事件 `@current-change` / `@size-change`，便于渐进替换。
- 切换每页条数时自动回到第 1 页。

### 7.5 EmptyState（新增）

```vue
<el-table ...>
  <template #empty><EmptyState text="暂无订单" desc="调整筛选条件后重试" /></template>
</el-table>
```

属性：`text` `desc` `icon`（Element Plus 图标名）`size`（sm/md/lg）。

### 7.6 StatusTag（新增）

```vue
<StatusTag :value="row.status" :map="ORDER_STATUS" />
<StatusTag text="已完成" type="success" />
<StatusTag :value="row.status" />   <!-- 原样展示 -->
```

字典来源：`src/utils/status.js`（`ENABLE_STATUS` / `ACTIVE_STATUS` / `ORDER_STATUS` / `AUDIT_STATUS` / `DISPUTE_STATUS` / `WORK_ORDER_STATUS`）。

### 7.7 BatchActionBar（新增，ITER-U03 前端）

```vue
<BatchActionBar :count="selection.length" @clear="clearSelection">
  <el-button size="small" type="success" :disabled="!selection.length" @click="runBatchAudit(true)">批量通过</el-button>
</BatchActionBar>
```

显示已选条数与 200 条上限提示；操作按钮由默认插槽提供。

### 7.8 BatchResultDialog（新增，ITER-U03 前端）

```vue
<BatchResultDialog v-model="resultVisible" :result="batchResult" @retry="retryFailed" />
```

展示 `BatchResultVO` 的总数/成功/跳过/失败与逐条明细；`retry` 事件回传 `failedIds`，由页面按上次参数重试。

## 九、校验与门禁

```bash
# 在 pc-admin 目录
npm run design:check          # 阈值 0，超阈值退出码 1
# 在仓库根目录
node scripts/check-design-tokens.js --verbose
node scripts/check-design-tokens.js --json
```

- 检测目标：`#hex`（3/4/6/8 位）、`rgb()/rgba()/hsl()/hsla()`。
- 豁免：`src/styles/tokens.css`（令牌定义）、`src/mock`（模拟数据色字段）、`node_modules`、`dist`。
- 误报防护：前后断言排除 Vue 插槽简写（`#default`）与 URL 锚点（`#app`）。
